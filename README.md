# Python Projects Repository

This repository contains multiple Python projects that cover various topics and exercises in Python programming, ranging from basic syntax to data structures, exceptions, and test-driven development.

## Projects List

- **python-data_structures**  
  Exercises and projects focusing on Python data structures such as lists, tuples, dictionaries, sets, and their manipulations.

- **python-exceptions**  
  Projects and exercises on handling exceptions in Python, creating custom exceptions, and using `try`, `except`, `finally` blocks.

- **python-hello_world**  
  Basic introductory projects and exercises to get started with Python programming.

- **python-if_else_loops_functions**  
  Exercises covering Python control structures such as if-else statements, loops (for/while), and function definitions.

- **python-import_modules**  
  Projects that involve importing and using Python modules, understanding module structure, and working with external packages.

- **python-more_data_structures**  
  Advanced exercises on data structures, including nested lists, complex dictionaries, and manipulation techniques.

- **python-test_driven_development**  
  Projects and exercises that focus on **Test-Driven Development (TDD)** in Python, writing unit tests using `unittest` and `doctest`, and creating robust code with testing.

## Usage

Each folder contains Python scripts and test files. You can run the tests using `unittest` or `doctest` depending on the project.

Example for test-driven development folder:

```bash
python3 -m unittest tests/6-max_integer_test.py
python3 -m doctest ./tests/5-text_indentation.txt
```
