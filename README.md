# holbertonschool-higher_level_programming

This repository contains projects related to **higher-level programming** at Holberton School, with a primary focus on **Python**.

The projects introduce fundamental programming concepts such as:
- Using the Python interpreter
- Printing text and variables
- Working with strings
- Indexing and slicing
- Following Python coding standards (PEP8 / pycodestyle)

Each directory in this repository represents a specific project or topic and includes practical exercises designed to build strong problem-solving and coding skills.
