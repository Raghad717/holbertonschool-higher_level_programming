# Python - More Data Structures

This project focuses on **advanced operations with Python data structures**, including **lists, dictionaries, and sets**.  
The tasks explore common patterns, data manipulation, and basic algorithms for working with collections.

All scripts are compatible with **Python 3.8+** and follow proper code style guidelines.

---

## Tasks Overview

### **0) 0-square_matrix_simple.py**
- Returns a **new matrix** with each element squared from the original matrix.

### **1) 1-search_replace.py**
- Replaces all occurrences of a specific value in a list with another value.

### **2) 2-uniq_add.py**
- Adds all **unique integers** in a list and returns the sum.

### **3) 3-common_elements.py**
- Returns a list of **common elements** between two lists.

### **4) 4-only_diff_elements.py**
- Returns a list of elements that are **unique to each list** (symmetric difference).

### **5) 5-number_keys.py**
- Counts the number of **keys in a dictionary**.

### **6) 6-print_sorted_dictionary.py**
- Prints a dictionary by **sorted keys** in ascending order.

### **7) 7-update_dictionary.py**
- Updates a dictionary with **new key-value pairs** or changes existing values.

### **8) 8-simple_delete.py**
- Deletes a key from a dictionary if it exists.

### **9) 9-multiply_by_2.py**
- Returns a new dictionary with all **values multiplied by 2**.

### **10) 10-best_score.py**
- Returns the **key with the highest value** in a dictionary.

### **11) 11-multiply_list_map.py**
- Multiplies all elements in a list by a specific factor using the **map function**.

### **12) 12-roman_to_int.py**
- Converts a **Roman numeral** string to its integer value.

---

## Requirements

- **Python version:** 3.8+  
- All scripts must start with: `#!/usr/bin/python3`  
- All files must be executable and end with a newline  
- Proper code style recommended (e.g., using `pycodestyle`)
