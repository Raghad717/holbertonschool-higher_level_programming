# Python - If/Else, Loops, and Functions

This project focuses on learning **conditional statements**, **loops**, and **functions** in Python.  
Each task helps build foundational programming skills through practical exercises.

All scripts are compatible with **Python 3.8+** and follow proper code style guidelines.

---

## Tasks Overview

### **0) 0-positive_or_negative.py**
- Determines if a randomly generated integer is **positive, negative, or zero** and prints the result.

### **1) 1-last_digit.py**
- Prints the **last digit** of a randomly generated number and displays a message depending on its value.

### **2) 2-print_alphabet.py**
- Prints the **alphabet in lowercase** using a loop.

### **3) 3-print_alphabt.py**
- Prints the alphabet **without 'q' and 'e'** in lowercase.

### **4) 4-print_hexa.py**
- Prints all numbers from 0 to 98 in **decimal and hexadecimal** format.

### **5) 5-print_comb2.py**
- Prints all possible **two-digit combinations** separated by commas.

### **6) 6-print_comb3.py**
- Prints all possible combinations of **two different digits** in ascending order.

### **7) 7-islower.py**
- Checks if a character is **lowercase**. Returns `True` or `False`.

### **8) 8-uppercase.py**
- Converts lowercase characters to **uppercase**.

### **9) 9-print_last_digit.py**
- Prints the **last digit** of a number using a function and returns it.

### **10) 10-add.py**
- Adds **two integers** and returns the result.

### **11) 11-pow.py**
- Computes the **power of a number** (a^b) using a function.

### **12) 12-fizzbuzz.py**
- Prints numbers from 1 to 100:  
  - Multiples of 3 → `Fizz`  
  - Multiples of 5 → `Buzz`  
  - Multiples of both 3 and 5 → `FizzBuzz`  

---

## Requirements

- **Python version:** 3.8+  
- All scripts must start with: `#!/usr/bin/python3`  
- All files must be executable and end with a newline  
- Proper code style recommended (e.g., using `pycodestyle`)
