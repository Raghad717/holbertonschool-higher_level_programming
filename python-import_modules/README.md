# Python - Import Modules

This project focuses on using **Python modules** and understanding how to organize code across multiple files.  
Each task introduces a different aspect of importing and using modules in Python.

All scripts are compatible with **Python 3.8+** and follow proper code style guidelines.

---

## Tasks Overview

### **0) 0-add.py**
- Defines a function that **adds two integers** and returns the result.  
- Demonstrates importing a function from another module.

### **1) 1-calculation.py**
- Imports a module containing basic arithmetic functions.  
- Performs calculations using **addition, subtraction, multiplication, and division**.

### **2) 2-args.py**
- Uses `sys.argv` to **sum all command-line arguments** passed to the script.  
- Demonstrates working with command-line input.

### **3) 3-infinite_add.py**
- Extends `2-args.py` by allowing **an unlimited number of integers** to be added.  
- Handles variable-length input and prints the total sum.

### **5) 5-variable_load.py**
- Demonstrates importing a **variable from another Python file** and using it in the script.

---

## Requirements

- **Python version:** 3.8+  
- All scripts must start with: `#!/usr/bin/python3`  
- All files must be executable and end with a newline  
- Proper code style recommended (e.g., using `pycodestyle`)
