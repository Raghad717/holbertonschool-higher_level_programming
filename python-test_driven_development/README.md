# Python - Test Driven Development

This repository contains Python programs and their respective tests, designed to practice **Test Driven Development (TDD)**. Each function is tested using **doctests** or **unittests**, depending on the project requirement.

## Directory Structure

```plaintext
python-test_driven_development/
├── tests/
│   ├── 0-add_integer.txt
│   ├── 2-matrix_divided.txt
│   ├── 3-say_my_name.txt
│   ├── 4-print_square.txt
│   ├── 5-text_indentation.txt
│   └── 6-max_integer_test.py
├── 0-add_integer.py
├── 2-matrix_divided.py
├── 3-say_my_name.py
├── 4-print_square.py
├── 5-text_indentation.py

```` 
---


## Files Overview

### Python Scripts

| File | Description |
|------|-------------|
| `0-add_integer.py` | Function that adds two integers and raises exceptions for invalid input. |
| `2-matrix_divided.py` | Function that divides all elements of a matrix by a number with proper error handling. |
| `3-say_my_name.py` | Function that prints a full name, validating string inputs. |
| `4-print_square.py` | Function that prints a square made of `#` characters. |
| `5-text_indentation.py` | Function that prints text with 2 new lines after `.`, `?`, and `:` characters. |
| `6-max_integer.py` | Function that returns the maximum integer in a list. |
