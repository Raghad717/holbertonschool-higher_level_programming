# Python Hello World – Holberton School

## Project Overview
This project is an introduction to **Python programming** at Holberton School.  
It focuses on learning how to use the Python interpreter, print output, work with
strings, apply slicing and indexing, follow coding style guidelines, and handle
basic formatting using f-strings.

Each task builds foundational Python skills while respecting strict constraints
such as line limits, no loops, no conditionals, and no string casting where specified.

---

## Learning Objectives
By completing this project, I learned how to:
- Use the Python interpreter
- Print text and variables using `print`
- Work with strings in Python
- Use indexing and slicing on strings
- Format output using f-strings
- Follow Python coding standards (pycodestyle)
- Write clean and readable Python scripts

---

## Tasks Summary

### 0️ Hello, print
**File:** `2-print.py`  
Prints a specific sentence using the `print` function.

---

### 1️ Print integer
**File:** `3-print_number.py`  
Prints an integer followed by text using **f-strings** without casting the number
to a string.

---

### 2️ Print float
**File:** `4-print_float.py`  
Prints a float with a precision of **2 decimal places** using f-strings.

---

### 3️ Print string
**File:** `5-print_string.py`  
Prints a string **three times**, followed by its **first 9 characters**.  
No loops or conditionals are used.

---

### 4️ Play with strings
**File:** `6-concat.py`

### 6️ Create a new sentence

object-oriented programming with Python

### 7️ The Zen of Python
