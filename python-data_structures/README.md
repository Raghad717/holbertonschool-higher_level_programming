# Python - Data Structures: Lists and Tuples

This repository contains solutions for the **Holberton School** project **Python - Data Structures**.  
The project focuses on mastering **lists**, **tuples**, basic sequence operations, and common patterns for manipulating these data structures in Python.

---

## Project Overview

The goal of this project is to practice:

- Working with **lists** and **tuples**  
- Accessing and modifying elements safely  
- Performing common operations on sequences  
- Implementing simple algorithms and data manipulations  

---

## Files and Tasks

### **Mandatory Tasks**

**0-print_list_integer.py**  
- Prints all integers in a list, one per line, using `str.format()`.

**1-element_at.py**  
- Safely retrieves an element from a list. Returns `None` if the index is out of range.

**2-replace_in_list.py**  
- Replaces an element at a given index in a list. Changes the original list only if the index is valid.

**3-print_reversed_list_integer.py**  
- Prints all integers of a list in **reverse order**, one per line.

**4-new_in_list.py**  
- Returns a **new copy** of a list with an element replaced at a specific index. The original list is unchanged.

**5-no_c.py**  
- Removes all occurrences of the characters `c` and `C` from a string without using `str.replace()`.

**6-print_matrix_integer.py**  
- Prints a **matrix of integers** with proper formatting.

**7-add_tuple.py**  
- Adds two tuples element-wise. Missing elements are treated as `0`, and extra elements beyond the first two are ignored.

**8-multiple_returns.py**  
- Returns a tuple containing the **length of a string** and its **first character**. Returns `None` if the string is empty.

**9-max_integer.py**  
- Finds and returns the **largest integer** in a list. Returns `None` if the list is empty.

**10-divisible_by_2.py**  
- Returns a list of booleans indicating whether each element is divisible by 2.

**11-delete_at.py**  
- Deletes an item at a specified index without using `pop()`.

**12-switch.py**  
- Switches the values of two variables in exactly **5 lines of code**.
